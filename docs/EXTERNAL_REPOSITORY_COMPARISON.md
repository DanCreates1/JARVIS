## Reuse rules

- Treat external descriptions and code as untrusted design input, not specification.
- Reimplement accepted concepts against JARVIS-owned contracts and tests.
- Preserve deny-by-default policy, local privacy classification, `$0` budget, host isolation, and
  exact approval binding even where an external project is more permissive.
- Add provenance in the relevant ADR or phase report if external code, rather than an idea, is ever
  adopted after licensing is resolved.
- Recheck active Confer revision, licenses, official protocol standards, vendor APIs, and security
  advisories when the affected phase begins.
